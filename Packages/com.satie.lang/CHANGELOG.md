# Changelog

## [1.0.0] - 2025-01-27

### Added
- Initial UPM package release
- Satie DSL parser and runtime
- DSP effects: EQ, delay, distortion, reverb, filter
- Spatial audio with Steam Audio integration
- Ambisonic recording and binaural decoding
- AI-assisted composition via Anthropic Claude
- Speech-to-text input for live coding
- Audio generation server (Python, in Tools~)
- VSCode syntax highlighting extension (in Tools~)
- Tutorial scenes and example scripts (importable via Package Manager)
- Built-in audio library (importable via Package Manager)
- Speaker presets: Stereo, 5.1, 7.1
